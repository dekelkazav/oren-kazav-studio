# אתר הסטודיו של אורן כזב

אתר תדמית וקטלוג סטטי (HTML/CSS/JS בלבד – בלי שרת ובלי התקנות).

## מבנה הקבצים
| קובץ | מה יש בו |
|---|---|
| `index.html` | מבנה העמוד והטקסטים הקבועים (כותרות, אודות, שלבי עבודה) |
| `data.js` | **כל התוכן שמתעדכן**: פרטי קשר, מוצרים בקטלוג, עבודות בגלריה |
| `styles.css` | העיצוב (צבעים מוגדרים בראש הקובץ תחת `:root`) |
| `app.js` | הלוגיקה – קטלוג, סינון, רשימת בחירות, שליחה לוואטסאפ |
| `images/` | כאן שמים את התמונות של המוצרים והעבודות |

## עדכונים נפוצים
- **מספר וואטסאפ** – ב-`data.js`, שדה `whatsapp`, בפורמט `9725XXXXXXXX`.
- **הוספת תמונה למוצר** – שומרים את התמונה ב-`images/` וממלאים את השדה `image`, למשל `image: "images/pesach.jpg"`.
- **הוספת מוצר** – מעתיקים בלוק מוצר קיים ב-`data.js` ומשנים את הפרטים (ה-`id` חייב להיות ייחודי).

## צפייה
פשוט פותחים את `index.html` בדפדפן.
