# אתר הסטודיו של אורן קצב

אתר תדמית וקטלוג – HTML/CSS/JS בלבד, בלי שרת ובלי מסד נתונים.

## הפעלה מקומית
```
npm start
```
ואז לפתוח בדפדפן: http://localhost:8080

## מבנה הקבצים
| קובץ / תיקייה | מה יש בו |
|---|---|
| `data.js` | **כל התוכן שמתעדכן**: פרטי קשר, קטגוריות, מוצרים, עבודות בגלריה ותמונות האינסטגרם |
| `index.html` | מבנה העמוד והטקסטים הקבועים (כותרות, "הסטודיו", "נעים להכיר", שלבי עבודה) |
| `styles.css` | העיצוב – צבעים וגופנים מוגדרים בראש הקובץ תחת `:root` |
| `app.js` | האינטראקציות: קטלוג, סינון, רשימת בחירות, וואטסאפ, אנימציות וגלילה |
| `images/works/` | תמונות העבודות בפורמט webp (נוצרות אוטומטית) |
| `images/brand/` | הלוגו בגרסה לבנה וכהה |
| `חומרים/` | חומרי מקור: הלוגו המקורי ותמונות מקור בתיקייה `תמונות` |
| `vendor/` | ספריית Lenis לגלילה חלקה |

## הוספת תמונות חדשות
1. שומרים את התמונות המקוריות בתיקייה `חומרים/תמונות`, עם שם באנגלית (למשל `rosh-hashana.jpg`).
2. מריצים:
   ```
   npm run images
   ```
   הסקריפט יוצר שתי גרסאות מכווצות לכל תמונה ב-`images/works`.
3. ב-`data.js`, במוצר המתאים, ממלאים את השדה `image` בשם הקובץ בלי סיומת: `image: "rosh-hashana"`.

## עדכונים נפוצים
- **מוצר חדש** – מעתיקים בלוק מוצר קיים ב-`data.js` ומשנים את הפרטים (ה-`id` חייב להיות ייחודי).
- **עבודה חדשה בגלריה** – מוסיפים שורה למערך `GALLERY` ב-`data.js`.
- **מספר וואטסאפ / טלפון** – בראש `data.js`, תחת `SITE`.

## מה לבדוק עם אורן
- הטקסטים ב"נעים להכיר" וב"הסטודיו" נכתבו כטיוטה – כדאי שאורן תעבור עליהם.
- למוצרי החגים ולמוצרי הילדים עדיין אין תמונות (מוצגת תמונה זמנית עם הלוגו).
- "כמות מינימלית" בכל מוצר היא הערכה – לעדכן לפי מה שאורן מציעה בפועל.
