# אתר הסטודיו של אורן קצב

אתר תדמית וקטלוג – HTML/CSS/JS בלבד, בלי שרת ובלי מסד נתונים.

## הפעלה מקומית
```
npm start
```
ואז לפתוח בדפדפן: http://localhost:8080

## מבנה הקבצים
| קובץ / תיקייה | מה יש בו |
|---|---|
| `data.js` | **כל התוכן שמתעדכן**: פרטי קשר, קטגוריות, מוצרים, עבודות בגלריה ותמונות האינסטגרם |
| `catalog-images.js` | נוצר אוטומטית ב-`npm run images`: כמה תמונות יש בכל אלבום בקטלוג. לא לערוך ידנית |
| `index.html` | מבנה העמוד והטקסטים הקבועים (כותרות, "הסטודיו", "נעים להכיר", שלבי עבודה) |
| `accessibility.html`, `privacy.html`, `terms.html` | הצהרת נגישות, מדיניות פרטיות ותנאי הזמנה |
| `styles.css` | העיצוב – צבעים וגופנים מוגדרים בראש הקובץ תחת `:root` |
| `app.js` | האינטראקציות: קטלוג, סינון, גלריית תמונות, רשימת בחירות, וואטסאפ, אנימציות וגלילה |
| `a11y.js` | תפריט הנגישות, שמופיע בכל העמודים |
| `images/works/` | תמונות העבודות בפורמט webp (נוצרות אוטומטית) |
| `images/catalog/` | תמונות האלבומים של הקטלוג, תיקייה לכל מוצר (נוצרות אוטומטית) |
| `images/brand/` | הלוגו בגרסה לבנה וכהה |
| `חומרים/` | חומרי מקור: הלוגו המקורי, תמונות עבודות בתיקייה `תמונות`, ותיקייה לכל אלבום בקטלוג |
| `vendor/` | ספריית Lenis לגלילה חלקה |

## הוספת תמונות חדשות
1. שומרים את התמונות המקוריות בתיקייה `חומרים/תמונות`, עם שם באנגלית (למשל `rosh-hashana.jpg`).
2. מריצים:
   ```
   npm run images
   ```
   הסקריפט יוצר שתי גרסאות מכווצות לכל תמונה ב-`images/works`.
3. ב-`data.js`, במוצר המתאים, ממלאים את השדה `image` בשם הקובץ בלי סיומת: `image: "rosh-hashana"`.

## הוספת תיקיית תמונות לקטלוג
כל תיקייה כזו מופיעה בקטלוג ככרטיס עם שם התיקייה, ובחלון המוצר יש גלריה של כל התמונות שבה.
1. יוצרים תיקייה בתוך `חומרים` עם שם המוצר (למשל `חורף`) ושמים בה את התמונות.
2. ב-`data.js` מוסיפים מוצר עם `folder: "חורף"`. אפשר להוסיף `cover: 3` כדי שהתמונה השלישית בתיקייה תהיה התמונה הראשית.
3. מריצים:
   ```
   npm run images
   ```

## עדכונים נפוצים
- **מוצר חדש** – מעתיקים בלוק מוצר קיים ב-`data.js` ומשנים את הפרטים (ה-`id` חייב להיות ייחודי).
- **עבודה חדשה בגלריה** – מוסיפים שורה למערך `GALLERY` ב-`data.js`.
- **מספר וואטסאפ / טלפון** – בראש `data.js`, תחת `SITE`.

## מה לבדוק עם אורן
- הטקסטים ב"נעים להכיר" וב"הסטודיו" נכתבו כטיוטה – כדאי שאורן תעבור עליהם.
- התיאורים של מוצרי התיקיות (חורף, חנוכה, מדבקות שם לילדים, שלטי פרספקס) נכתבו לפי התמונות – כדאי שאורן תאשר אותם.
- למוצרי ראש השנה, פורים, פסח ותחילת שנה עדיין אין תמונות (מוצגת תמונה זמנית עם הלוגו).
- "כמות מינימלית" בכל מוצר היא הערכה – לעדכן לפי מה שאורן מציעה בפועל.
